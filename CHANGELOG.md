# Changelog

## [0.1.0] - 2026-11-12

### Added

- `/skill-toggle` picker with repository and global scope, filter, bulk toggle, and catalog token totals.
- `/skill-toggle on|off <skill> [--global]`, `reset <skill>`, and `list`, with Tab completion.
- Repository rules with `*` wildcards, a `version` field, and a JSON schema for the settings file.
- Settings shared across worktrees and clones of one repository.
